创建视频生成任务

POST /v1/videos
当前服务使用 HTTP，API 密钥会以明文网络流量传输。请仅在可信网络中使用。
无需上传音频。
首尾帧模式按首帧、尾帧顺序提交。
H3 要求宽高为 32 的倍数，因此 720p 使用官方推荐的 1344×768。
参照官方 H3：整数 4–15 秒，默认 5 秒。

调用流程

1. 创建POST /v1/videos，返回任务 ID
2. 查询GET /v1/videos/{id}，每 3 秒轮询
3. 下载GET /v1/videos/{id}/content

任务历史

使用上方填写的 API 密钥读取；有进行中的任务时每 5 秒自动刷新。历史与视频保存在服务端文件数据库，网关重启后依然可查可播。
填写 API 密钥后点击“刷新历史”。

接口参考

请求格式：本地统一接口全部使用 JSON。上传图片、视频、音频时，将公网 URL 或 data URL 写入 content[]。

统一入口与鉴权

BASE URL http://localhost:8090
Content-Type: application/json Authorization: Bearer <API_KEY>

所有生成、查询和下载请求都通过统一端口 8090。请求头必须携带：

Authorization: Bearer <API_KEY>

网关根据 JSON content[].role 自动识别文生视频、首帧/尾帧/首尾帧图生视频或参考生成，并路由到对应本地模型。

任务类型

task能力输入媒体模型字段
t2va文生视频和同步音频无MiniMax-H3-FL2VA
fl2va首帧 / 尾帧 / 首尾帧图生视频和同步音频first_frame、last_frame 图片（可单可组合）MiniMax-H3-FL2VA
ref2va图片参考生成（支持多张，音频可选，用于指定声音）参考图片 1–4 张，音频可搭配MiniMax-H3-Ref2VA
ref2va视频参考生成input_reference 视频，使用源音轨MiniMax-H3-Ref2VA
参考生成规则：至少需要图片或视频之一，音频不能作为唯一参考；纯图片参考为实验性功能（模型自行生成声音），搭配参考音频可指定音色。文生视频、首帧/尾帧/首尾帧图生视频、图片+音频参考均已真实生成验证。任务历史保存在服务端文件数据库（gateway_data/h3_gateway.db），生成视频落盘于 gateway_data/videos/，网关重启不丢失。

JSON 请求参数

参数类型 / 必填说明允许值 / 建议
modelstring / 是本地统一模型名称MiniMax-H3
contentarray / 是多模态内容数组，至少包含一个非空文本项见 content 项目表
resolutionstring / 是本地已启用的分辨率档位480P、768P；2K 未启用
durationinteger / 是目标时长，单位秒4–15，默认建议 5
ratiostring / 是文生视频/图片参考/视频参考按所选比例出片；首尾帧图生视频由首帧图片比例决定（传 adaptive）21:9、16:9、4:3、1:1、3:4、9:16、adaptive（仅首尾帧模式建议）
generation_configobject / 否本地推理参数省略时使用下表默认值
generation_config.num_inference_stepsinteger / 否扩散去噪次数基础 H3 建议 50；2 仅供冒烟测试
generation_config.seedinteger / 否随机种子，固定后便于复现默认 1101
generation_config.flow_shiftnumber / 否视频噪声调度偏移默认 12
generation_config.audio_flow_shiftnumber / 否音频噪声调度偏移默认 3.0

content[] 项目

type字段role用途与限制
texttext不填必填且非空，描述主体、动作、镜头和声音
image_urlimage_url.urlfirst_frame首帧图生视频；支持公网 URL 或 data:image URL；与 last_frame 同时提交即为首尾帧模式
image_urlimage_url.urlreference_imageRef2VA 参考图片，可提交多张（本部署最多 4 张）实现多主体一致性；搭配 reference_audio 可指定音色
audio_urlaudio_url.urlreference_audioRef2VA 参考音频；支持公网 URL 或 data:audio URL
video_urlvideo_url.urlreference_videoRef2VA 参考视频；支持公网 URL 或 data:video URL，使用源音轨
image_urlimage_url.urllast_frame尾帧图生视频；单独提交即尾帧模式；支持公网 URL 或 data:image URL
关于推理步数：本地 vLLM 基础模型建议使用 50 步（该字段不属于 MiniMax 云 V2 接口）。2 步仅用于部署冒烟测试，画质不具有参考价值。只有安装并启用匹配的 FastH3/Turbo 蒸馏适配器后，才能按对应适配器要求使用 4 或 5 步；当前服务未启用该适配器。

HTTP含义处理建议
400JSON、参数或媒体组合不合法检查 extra_params JSON；data URL 请用 --form-string
401缺少密钥或密钥错误检查 Authorization: Bearer
404任务 ID 不存在或结果已清理核对 ID，重新创建任务
422字段类型或必填参数错误按参数表检查字段类型
500推理失败、显存不足或当前组合不受支持查看响应 error；降低分辨率/时长或调整媒体组合
409任务尚未完成继续查询任务状态后再下载
415Content-Type 错误必须使用 application/json
503后端服务未就绪稍后重试并检查 /health
